Documentation

Concept documentation for AetherArch

1. Introduction

AetherArch is a conceptual evolution of Arch Linux. It keeps the rolling-release model, the KISS philosophy, and the power-user focus, while adding deeper modularity, a hybrid package system, and a coherent modern aesthetic.

2. Core Principles

  • Simplicity first — but not at the cost of capability
  • User is in full control
  • Modularity by design
  • Bleeding edge with optional stability layers
  • Aesthetic coherence as a productivity feature

3. Package Management

The main tool is aether-pkg, fully compatible with pacman syntax while adding:

  • Native container packages
  • Source builds with dependency tracking
  • Transactional updates (optional)
  • Better AUR integration
aether-pkg -Syu
aether-pkg -S neovim-aether
aether-pkg search zfs
aether-pkg container run alpine

4. Window Manager — AetherWM

AetherWM is a dynamic tiling window manager with floating support, inspired by the best of i3, Hyprland and bspwm, but with predictive focus and layout memory.

5. Kernel

linux-aether is a custom kernel based on mainline with selected performance and modularity patches. Modules can be loaded/unloaded more aggressively at runtime.

6. Installation (Conceptual)

In a real version, the process would be very close to Arch:

  1. Boot the ISO
  2. Partition & mount
  3. Run aetherstrap (improved pacstrap)
  4. Configure & reboot

7. Status

This entire project is currently a design and architecture concept. There is no real ISO, no real packages, and no real repository. It exists as a visual and philosophical exploration of what a more ambitious Arch-based system could look like.
