Core Features

Everything you love about Arch, amplified.

⚡

Hybrid Package Manager

pacman + source builds + native container packages in a single unified interface. Install from AUR, compile from source, or run isolated containers without leaving the terminal.

🧠

Intelligent Tiling (AetherWM)

Next-generation window manager with adaptive layouts, predictive focus, and deep keyboard-driven workflows. Built for power users who never touch the mouse.

🧬

Dynamic Kernel Modules

Kernel with hot-swappable modules and runtime configuration. Load only what you need, when you need it. Extreme performance tuning made simple.

📦

Native Container Runtime

First-class support for rootless containers integrated at the system level. Run services, apps, or entire environments without Docker bloat.

🌑

Deep Dark Aesthetic

Every component designed around a coherent dark + cyan neon visual language. Consistent, beautiful, and distraction-free.

🔧

Extreme Modularity

Almost nothing is forced. Build your system from a minimal base and add only what you actually use. True DIY philosophy taken further.

Philosophy

“Keep it simple, but never stop evolving.”

AetherArch is not a beginner distribution. It is built for those who already understand Linux deeply and want more control, more performance, and more beauty.

We take the Arch principles — simplicity, modernity, pragmatism, user-centrism — and push them into new territory: deeper modularity, smarter defaults for power users, and a visual identity that matches the technical ambition.

Rolling Extreme Always on the bleeding edge, with carefully tested stability layers.
User in Control You decide the shape of your system. We just give you sharper tools.
Aesthetic as Function A coherent visual language reduces cognitive load and increases focus.

Technical Overview

Base Arch Linux (rolling)
Init systemd + aether-init hooks
Package Manager aether-pkg (pacman compatible)
Window Manager AetherWM (tiling + floating)
Kernel linux-aether (custom patches)
Shell zsh + aether-prompt
Containers Native rootless (aether-ct)
Target Users Advanced / Power users
