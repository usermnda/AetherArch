Roadmap

Conceptual development phases

Phase 0 — Concept (Current)

  • Visual identity & logo
  • Website & branding
  • Core philosophy definition
  • UI mockups (login, terminal, package manager, desktop)

Phase 1 — Foundation

  • Custom ISO based on Arch
  • aether-pkg prototype (pacman wrapper + extras)
  • Basic AetherWM (tiling)
  • Default dark theme package

Phase 2 — Core Experience

  • Hybrid package sources (binary + source + container)
  • Improved installer (aetherstrap)
  • Kernel linux-aether first public release
  • Documentation site

Phase 3 — Advanced Features

  • Native rootless containers
  • Transactional updates (optional)
  • Predictive focus & layout memory in AetherWM
  • System snapshots & easy rollback

Phase 4 — Polish & Ecosystem

  • Official repositories
  • AUR helper deeply integrated
  • Community themes & configs
  • Hardware enablement improvements

Notes

This roadmap is purely speculative and part of the concept kit. No real development is currently happening. It serves as a vision of how such a project could evolve.
